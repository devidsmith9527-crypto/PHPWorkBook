៨.១.១ អ្វីទៅជា PDO? (PHP Data Objects Overview)

Database Abstraction Layer: Universal Interface for Multi-Engine Connectivity

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY
🎯 គោលគំនិត ៖ PDO (PHP Data Objects) គឺជា Database Abstraction Layer មួយក្នុង PHP ដែលផ្តល់នូវ Interface រួមមួយប្រកបដោយសុវត្ថិភាពខ្ពស់ ក្នុងការតភ្ជាប់ និងបញ្ជា Database Engines ផ្សេងៗគ្នា។

C1 លក្ខណៈស្នូលនៃ PDO

  • Data Abstraction Layer ៖ កូដ PHP សរសេរតែមួយទម្រង់ អាចបញ្ជា Database ច្រើនប្រភេទ។
  • Database Portability ៖ គាំទ្រ RDBMS ដល់ទៅ ១២ ប្រភេទផ្សេងគ្នា (MySQL, PostgreSQL, SQLite, Oracle, MS SQL Server...)។
  • Full OOP Interface ៖ ដំណើរការតាមបែប Object-Oriented 100% ស្អាតបាត និងស៊ីសង្វាក់ជាមួយ PHP 8 Frameworks (Laravel, Symfony)។

សន្តិសុខ និងសុវត្ថិភាព

  • គាំទ្រ Prepared Statements ដោយផ្ទាល់ ការពារ SQL Injection ១០០%។

១. Old MySQLi Approach

២. Modern PDO Approach

៨.២.១ រចនាសម្ព័ន្ធ DSN (Data Source Name Anatomy)

Connection Parameters: Drivers, Hostnames, Database Names, and Character Encodings

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY
🎯 គោលគំនិត ៖ DSN (Data Source Name) គឺជា String ពិសេសមួយដែលប្រាប់ទៅកាន់ PDO នូវ Driver ប្រភេទណាដែលត្រូវប្រើ, អាសយដ្ឋាន Host, ឈ្មោះ Database, និង Character Encoding។

C2 សមាសភាគទាំង ៤ នៃ DSN

$dsn = "mysql:host=localhost;dbname=db_university_app;charset=utf8mb4";
  • mysql: ៖ PDO Driver prefix សម្គាល់ប្រភេទ Database (បើ PostgreSQL គឺ pgsql:, SQLite គឺ sqlite:)។
  • host=localhost ៖ អាសយដ្ឋាន Server (IP Address ឬ Hostname)។
  • dbname=... ៖ ឈ្មោះ Database ដែលត្រូវភ្ជាប់។
  • charset=utf8mb4 ៖ កំណត់ Encoding អក្សរខ្មែរ និង Emoji មិនឱ្យចេញសញ្ញា ???។

ហេតុអ្វីត្រូវបញ្ជាក់ Charset ក្នុង DSN?

ការកំណត់ charset=utf8mb4 ដោយផ្ទាល់នៅក្នុង DSN គឺជា ស្តង់ដារសន្តិសុខដ៏សំខាន់បំផុត!

ប្រសិនបើមិនបានបញ្ជាក់ Charset ក្នុង DSN ទេ Database Connection អាចនឹងងាយរងគ្រោះដោយសារការវាយប្រហារ Charset-based SQL Injection តាមរយៈ Multibyte Characters ពិសេស!
