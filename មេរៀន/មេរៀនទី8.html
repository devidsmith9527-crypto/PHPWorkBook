៨.១.១ អ្វីទៅជា PDO? (PHP Data Objects Overview & Technical Matrix) C2

ក. និយមន័យ (Definition)៖
• PDO (PHP Data Objects)៖ គឺជា Database Abstraction Layer មួយដែលត្រូវបានបង្កើតឡើងក្នុង PHP (ចាប់ពី PHP 5.1+ និងអភិវឌ្ឍយ៉ាងខ្លាំងក្នុង PHP 8) សម្រាប់ផ្តល់នូវ Interface រួមមួយដែលមានសុវត្ថិភាពខ្ពស់ក្នុងការតភ្ជាប់ និងបញ្ជា Database Engines ផ្សេងៗគ្នា។
• Database Portability (ភាពងាយស្រួលក្នុងការប្តូរ Database): ខុសពី MySQLi ដែលដំណើរការបានតែជាមួយ MySQL មួយមុខ PDO គាំទ្រ RDBMS Drivers រហូតដល់ទៅ ១២ ប្រភេទផ្សេងគ្នា (ដូចជា MySQL, PostgreSQL, SQLite, MS SQL Server, Oracle) តែតាមរយៈ Code Base រួមមួយ!
ខ. តារាងប្រៀបធៀបលក្ខណៈបច្ចេកទេស (PDO vs MySQLi Comparison Table)៖
លក្ខណៈ (Technical Feature) MySQLi Extension PDO (PHP Data Objects)
ការគាំទ្រ Database (Database Support) គាំទ្រតែ **MySQL / MariaDB** មួយគត់ ✓ គាំទ្រ RDBMS ដល់ទៅ ១២ ប្រភេទ
ទម្រង់សរសេរកូដ (Coding Paradigm) គាំទ្រ Procedural និង OOP គួបផ្សំ ✓ OOP Standard 100% ស្អាត និងទំនើប
Named Parameters ក្នុង Security Queries មិនគាំទ្រឡើយ (ប្រើបានតែសញ្ញា ?) ✓ គាំទ្រ :name (ងាយស្រួលសរសេរ)
ការចាប់កំហុស (Error Trapping) ប្រើប្រាស់ Error Codes / Warning String ✓ ប្រើប្រាស់ `PDOException` ទំនើប
គ. កូដប្រៀបធៀបទម្រង់ភ្ជាប់ (MySQLi vs PDO Connection Syntax)៖
connection_paradigm_comparison.php
<?php
// --- 1. OLD MYSQLI APPROACH (Procedural & Single DB Support) ---
$mysqli_conn = mysqli_connect("localhost", "root", "", "db_university_app");
if (!$mysqli_conn) {
    die("MySQLi Failed: " . mysqli_connect_error());
}

// --- 2. MODERN PDO APPROACH (OOP, Portable & Secure Abstraction) ---
$dsn = "mysql:host=localhost;dbname=db_university_app;charset=utf8mb4";
try {
    $pdo = new PDO($dsn, "root", "");
    // PDO Object ភ្ជាប់ជោគជ័យ និងត្រៀមខ្លួនប្រើប្រាស់!
} catch (PDOException $e) {
    die("PDO Connection Failed: " . $e->getMessage());
}
?>

៨.២.១ DSN Anatomy & Essential PDO Options/Attributes C3

ក. និយមន័យ DSN (Data Source Name Anatomy)៖
DSN (Data Source Name) គឺជា String ពិសេសមួយដែលប្រាប់ទៅ PDO នូវ Driver ប្រភេទណាដែលត្រូវប្រើប្រាស់, អាសយដ្ឋាន Host, ឈ្មោះ Database, Port, និងប្រភេទ Character Set encoding៖
// DSN Formatting Structure $dsn = "mysql:host=HOSTNAME;dbname=DATABASE_NAME;charset=utf8mb4;port=3306";
ខ. ការកំណត់ PDO Attributes/Options សំខាន់ៗ (Core PDO Attributes Matrix)៖
PDO Attribute Key តម្លៃកំណត់ (Recommended Value) ពន្យល់ពីផលប្រយោជន៍
PDO::ATTR_ERRMODE PDO::ERRMODE_EXCEPTION ឱ្យ PDO បោះ **Exception Error** ពេលមានបញ្ហា ងាយស្រួល Catch
PDO::ATTR_DEFAULT_FETCH_MODE PDO::FETCH_ASSOC ទាញយកទិន្នន័យជា **Associative Array** ស្វ័យប្រវត្តិ
PDO::ATTR_EMULATE_PREPARES false បិទ Emulation ឱ្យ MySQL ធ្វើ Prepared Statement ផ្ទាល់ (សុវត្ថិភាពខ្ពស់)
គ. កូដ PHP ភ្ជាប់ PDO ប្រកបដោយស្តង់ដារ (Clean PDO Connection Script)៖
pdo_standard_connection.php
<?php
declare(strict_types=1);

$host = "localhost";
$db   = "db_university_app";
$user = "root";
$pass = "";
$charset = "utf8mb4";

$dsn = "mysql:host={$host};dbname={$db};charset={$charset}";

$options = [
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES   => false,
];

try {
    $pdo = new PDO($dsn, $user, $pass, $options);
    echo "<span style='color:green; font-weight:bold;'>[Success] ភ្ជាប់ទៅកាន់ MySQL Database តាម PDO ជោគជ័យ!</span>";
} catch (PDOException $e) {
    echo "<span style='color:red;'>[Error] ការភ្ជាប់បរាជ័យ៖ " . $e->getMessage() . "</span>";
}
?>

៨.៣ ការគ្រប់គ្រង Exception Handling តាមរយៈ `try...catch` C3 C4

៨.៣.១ `PDOException` Trapping & Credentials Exposure Prevention C4

ក. និយមន័យ និងហានិភ័យ (Exception Trapping & Security Risk)៖
• ហានិភ័យនៃការលេចធ្លាយព័ត៌មាន (Information Disclosure Vulnerability): ប្រសិនបើកូដភ្ជាប់ Database កើតមាន Error (ដូចជា បញ្ចូល Password ខុស ឬ Database Name ខុស) ហើយយើង **មិនបានប្រើ `try...catch`** នោះ PHP នឹងបង្ហាញ Fatal Error Uncaught Exception លើទំព័រ Web Browser ដោយបង្ហាញទាំង **Database Password, Hostname, និង Path ឯកសារក្នុង Server** ឱ្យ Hacker មើលឃើញ!
ខ. កូដ PHP បង្ហាញពីការតេស្តចាប់ Error សុវត្ថិភាព (Safe Exception Catching)៖
pdo_safe_exception_handling.php
<?php
// ឧទាហរណ៍៖ តេស្តប្តូរឈ្មោះ Database ទៅដកឃ្លាខុស ដើម្បីឱ្យវាលោត Exception
$bad_dsn = "mysql:host=localhost;dbname=db_invalid_name;charset=utf8mb4";

try {
    $pdo = new PDO($bad_dsn, "root", "");
} catch (PDOException $e) {
    // 1. កត់ត្រាកំហុសពិតប្រាកដចូលក្នុង System Log សម្រាប់ Developer ពិនិត្យ (Production Standard)
    error_log($e->getMessage());

    // 2. បង្ហាញសារទន់ភ្លន់ សុវត្ថិភាពខ្ពស់ ជូនអ្នកប្រើប្រាស់ (កុំឱ្យលេច Password)
    die("<div style='padding:15px; background:#FEE2E2; border:1px solid #EF4444; border-radius:6px; color:#991B1B;'>
            <b>[ប្រព័ន្ធមានបញ្ហា]:</b> មិនអាចតភ្ជាប់ទៅកាន់ Database ពេលនេះបានឡើយ! សូមព្យាយាមម្តងទៀតនៅពេលក្រោយ។
         </div>");
}
?>
គ. លទ្ធផលបង្ហាញជារូបភាពសុវត្ថិភាព (User Friendly Error Output)៖
Safe User Output (No Leakage)
[ប្រព័ន្ធមានបញ្ហា]: មិនអាចតភ្ជាប់ទៅកាន់ Database ពេលនេះបានឡើយ! សូមព្យាយាមម្តងទៀតនៅពេលក្រោយ។
ឃ. ការអនុវត្តល្អៗក្នុង Enterprise Systems (Production Best Practices)៖
• `error_log()` Function: ក្នុងដំណាក់កាល Development យើងអាច echo $e->getMessage() ដើម្បីស្វែងរក Bug។ ប៉ុន្តែពេល Deploy ទៅកាន់ Production Web Server ត្រូវតែប្រើ error_log($e->getMessage()) ដើម្បីរុញសារ Error ទៅទុកក្នុងឯកសារ php_error.log របស់ Server វិញ!

• OOP Singleton Pattern (PHP 8 Design Pattern): គឺជា Design Pattern ខ្ពស់មួយដែលធានាថា PDO Connection Instance ត្រូវបានបង្កើតឡើង **តែ ១ ដងគត់ក្នុង Memory** ក្នុងអំឡុងពេល Page Execution ការពារការបង្កើត Connection ច្រើនដងហួសហេតុ (Overhead Memory Connection Leak)!
ខ. កូដ PHP 8 OOP Singleton Database Class ពេញលេញ (Production Grade Wrapper)៖
Database.php (PHP 8 OOP Singleton)
<?php
declare(strict_types=1);

class Database {
    private static ?PDO $instance = null;

    // Private Constructor ការពារមិនឱ្យ new Database() ពីខាងក្រៅបាន
    private function __construct() {}

    public static function getInstance(): PDO {
        if (self::$instance === null) {
            $dsn = "mysql:host=localhost;dbname=db_university_app;charset=utf8mb4";
            $options = [
                PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                PDO::ATTR_EMULATE_PREPARES   => false,
            ];
            try {
                self::$instance = new PDO($dsn, "root", "", $options);
            } catch (PDOException $e) {
                die("Database Singleton Error: " . $e->getMessage());
            }
        }
        return self::$instance;
    }
}

// --- របៀបហៅប្រើប្រាស់តាមទំព័រផ្សេងៗ (Usage Example) ---
$pdo = Database::getInstance();
echo " Singleton Database Instance ត្រូវបានបង្កើត និងទាញយកជោគជ័យ!";
?>

• ដំណោះស្រាយ Lab 8.8 & 8.9 (Production Enterprise PDO Singleton Wrapper) C6៖
Database.php (Enterprise Grade Singleton)
<?php
declare(strict_types=1);

class Database {
    private static ?PDO $connection = null;

    // Private Constructor & Clone to prevent direct instantiation
    private function __construct() {}
    private function __clone() {}

    public static function getConnection(): PDO {
        if (self::$connection === null) {
            $host = "localhost";
            $db   = "db_university_app";
            $user = "root";
            $pass = "";
            $dsn  = "mysql:host={$host};dbname={$db};charset=utf8mb4";

            $options = [
                PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                PDO::ATTR_EMULATE_PREPARES   => false,
            ];

            try {
                self::$connection = new PDO($dsn, $user, $pass, $options);
            } catch (PDOException $e) {
                error_log("[PDO Singleton Error] " . $e->getMessage());
                die("<h3 style='color:red;'>[System Error]: Unable to connect to database.</h3>");
            }
        }
        return self::$connection;
    }
}

// --- Usage Test ---
$db = Database::getConnection();
echo "Enterprise PDO Singleton Wrapper Ready!";
?>
