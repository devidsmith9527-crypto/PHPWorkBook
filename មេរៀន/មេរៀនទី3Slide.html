៣.១.១ Indexed Array (អារ៉េតាមលំដាប់សន្ទស្សន៍)

Numeric Index Collections: Definition, Declaration, and Array Access

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY
🎯 គោលគំនិត ៖ Indexed Array រក្សាទុកធាតុនីមួយៗដោយប្រើសន្ទស្សន៍ជាលេខរៀង (Numeric Index) ស្វ័យប្រវត្តិចាប់ពី 0, 1, 2... បន្តបន្ទាប់។

C1 ទម្រង់ទូទៅ (General Syntax)

$array_name = [item0, item1, item2, ...]; $first_item = $array_name[0]; // ចាប់យកធាតុទី១តាម index 0

ចំណុចសម្គាល់ ៖ ក្នុង PHP ទំនើប ការប្រើប្រាស់តង្កៀបជ្រុង [] ត្រូវបានណែនាំឱ្យប្រើប្រាស់ជំនួសឱ្យពាក្យបញ្ជា array() ចាស់។

កូដ PHP អនុវត្តជាក់ស្តែង

<?php $languages = ["PHP 8", "JavaScript", "SQL"]; echo "ភាសាទី១៖ " . $languages[0] . " | ភាសាទី៣៖ " . $languages[2]; ?>
ភាសាទី១៖ PHP 8 | ភាសាទី៣៖ SQL

៣.១.២ Associative Array (អារ៉េតាមគូសោ-តម្លៃ Key-Value)

Named Key Collections: Mapping Meaningful Keys to Data Elements

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY
🎯 គោលគំនិត ៖ Associative Array ប្រើប្រាស់ Named Keys (String) ភ្ជាប់ទៅកាន់តម្លៃ (Key => Value) ដែលងាយស្រួលតំណាងឱ្យ Entity Record (ដូចជា Student, Product)។

C2 ទម្រង់ទូទៅ (General Syntax)

$array_name = [ "key1" => value1, "key2" => value2 ]; $val = $array_name["key1"]; // ចូលប្រើតាមឈ្មោះ Key

អត្ថប្រយោជន៍ ៖ ឈ្មោះ Key ជួយឱ្យកូដមានភាពងាយស្រួលយល់ និងមិនបាច់ចាំលេខ Index រញ៉េរញ៉ៃឡើយ។

កូដ PHP អនុវត្តជាក់ស្តែង

<?php $student = [ "id" => "AU-CS-001", "name" => "សុខ ជា", "gpa" => 3.85 ]; echo "អត្តលេខ៖ {$student['id']} | ឈ្មោះ៖ {$student['name']} | GPA: {$student['gpa']}"; ?>
អត្តលេខ៖ AU-CS-001 | ឈ្មោះ៖ សុខ ជា | GPA: 3.85

៣.១.៣ Multidimensional Array (អារ៉េពហុវិមាត្រ)

Arrays of Arrays: Representing Tabular and Relational Data Structures

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY
🎯 គោលគំនិត ៖ Multidimensional Array គឺជាអារ៉េដែលមានផ្ទុកអារ៉េមួយទៀត ឬច្រើននៅខាងក្នុងវា (Array of Arrays) ប្រើប្រាស់សម្រាប់តំណាងឱ្យទិន្នន័យតារាង Database (Rows & Columns)។

C2 រចនាសម្ព័ន្ធតារាង

$matrix = [ ["key1" => val1, "key2" => val2], ["key1" => val3, "key2" => val4] ]; $val = $matrix[row_index]["key_name"];

សន្ទស្សន៍ទី១ [0] សំដៅលើជួរដេក (Row/Record) ហើយសន្ទស្សន៍ទី២ ['title'] សំដៅលើជួរឈរ (Field/Column)។

កូដ PHP អនុវត្តជាក់ស្តែង

<?php $products = [ ["title" => "Laptop Dell", "price" => 850], ["title" => "Mouse Logitech", "price" => 25] ]; echo "ទំនិញទី១៖ " . $products[0]["title"] . " - តម្លៃ៖ " . $products[0]["price"] . " $"; ?>
ទំនិញទី១៖ Laptop Dell - តម្លៃ៖ 850 $

៣.២ អនុគមន៍ដែលផ្តល់ស្រាប់ (Built-in Functions)

Core Standard Library: Array Manipulation, String Processing & Inspection

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY

Array Functions

  • count($arr) ៖ រាប់ចំនួនធាតុសរុបក្នុង អារ៉េ
  • array_push($arr, $val) ៖ បន្ថែមធាតុថ្មីទៅចុងអារ៉េ
  • in_array($val, $arr) ៖ ពិនិត្យវត្តមានធាតុក្នុងអារ៉េ
  • array_pop($arr) ៖ ដកធាតុចុងក្រោយចេញ

String Functions

  • strlen($str) ៖ រាប់ចំនួនតួអក្សរនៃ String
  • strtoupper($str) ៖ បំប្លែងតួអក្សរទៅជាអក្សរធំ
  • strtolower($str) ៖ បំប្លែងទៅជាអក្សរតូច
  • trim($str) ៖ កាត់ space មុខនិងក្រោយចោល

Inspection & Debug

  • var_dump($var) ៖ បង្ហាញ Type, Length & Value លម្អិត
  • print_r($arr) ៖ បង្ហាញរចនាសម្ព័ន្ធ Array ឱ្យងាយស្រួលមើល
  • is_array($var) ៖ ផ្ទៀងផ្ទាត់ថាជា Array ឬទេ

៣.៣ អនុគមន៍បង្កើតដោយអ្នកប្រើប្រាស់ (User Defined Functions)

Function Architecture: Breakdown of Void vs Return Value Functions

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY
🎯 ការបែងចែក ៖ User Defined Functions ត្រូវបានបែងចែកជា ២ ក្រុមធំៗ គឺ None Return Value (Void) និង Return Value ដែលនីមួយៗអាចមាន ឬគ្មាន Parameters។

១. Function None Return Value (Void)

អនុគមន៍ដែលគ្រាន់តែប្រតិបត្តិកូដមួយចំនួន (ដូចជាបង្ហាញ UI ឬ echo) ដោយគ្មានបញ្ជា return ឡើយ ៖

  • ក. Void - Without Parameter ៖ គ្មាន parameter និងគ្មាន return
  • ខ. Void - With Parameters ៖ ទទួល parameter តែគ្មាន return

២. Function Return Value (មាន Return)

អនុគមន៍ដែលធ្វើការគណនា រួចបញ្ជូនលទ្ធផលត្រឡប់មកក្រៅវិញតាមរយៈបញ្ជា return ៖

  • ក. Return - Without Parameter ៖ គ្មាន parameter តែមាន return
  • ខ. Return - With Parameters ៖ មាន parameter និងមាន return

៣.៤ លក្ខណៈពិសេសអនុគមន៍ PHP 8 (Modern PHP Features)

Strict Types, Default Parameters, and Arrow Functions (fn() => expression)

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY

C4 គោលគំនិតគន្លឹះក្នុង PHP 8

  • Strict Types (declare(strict_types=1);) ៖ បង្ខំឱ្យ PHP ផ្ទៀងផ្ទាត់ Type នៃ Argument និង Return Value យ៉ាងតឹងរ៉ឹងបំផុត មិនអនុញ្ញាត Type Coercion ឡើយ។
  • Default Parameter Values ៖ កំណត់តម្លៃលំនាំដើមក្នុង Parameter បើ Caller មិនបានបញ្ជូនតម្លៃមក។
  • Arrow Functions (fn()) ៖ សរសេរ Function កាត់ខ្លី និង Auto-capture អថេរពី Outer Scope ស្វ័យប្រវត្តិ។

Detailed Conceptual Explanations: Arrays, Built-ins, Void vs Return, and File Inclusion

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY

• ចម្លើយ Q3.1, Q3.2 & Q3.3

• Q3.1 (Indexed vs Associative) ៖ Indexed Array ប្រើសន្ទស្សន៍លេខរៀង ($a[0])។ Associative Array ប្រើ String Key ($user['name']) ដែលងាយស្រួលសម្គាល់អត្ថន័យទិន្នន័យ។

• Q3.2 (Built-ins) ៖ count() រាប់ចំនួនធាតុអារ៉េ; strlen() រាប់ប្រវែងអក្សរ String; var_dump() បង្ហាញ Type, Length និង Value លម្អិត។

• Q3.3 (Void vs Return) ៖ Void Function គ្រាន់តែប្រតិបត្តិ (echo) គ្មាន return ឡើយ។ Return Value Function បញ្ជូនតម្លៃត្រឡប់មកក្រៅតាមរយៈ return ដើម្បីយកទៅប្រើបន្ត។

• ចម្លើយ Q3.4 & Q3.5

• Q3.4 (Directives Comparison) ៖ include បោះ Warning និងរត់កូដបន្ត; require បោះ Fatal Error បញ្ឈប់ Script ភ្លាមៗ។ បញ្ជាដែលមាន _once ការពារ Load ជាន់គ្នា។ សម្រាប់ DB Config ត្រូវតែប្រើ require_once ជាដាច់ខាត។

• Q3.5 (Function Classification) ៖
- Void W/O: function a(): void { echo "A"; }
- Void With: function b(string $p): void { echo $p; }
- Ret W/O: function c(): int { return 10; }
- Ret With: function d(int $x): int { return $x * 2; }
