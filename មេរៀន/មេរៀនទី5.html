ក. និយមន័យ និងការប្រៀបធៀប (Definition & Paradigm Shift)៖
• Procedural Programming: គឺជាទម្រង់សរសេរកូដដែលផ្តោតលើ **Functions/Procedures** រត់តាមលំដាប់លំដោយ (Top-to-bottom)។ ទិន្នន័យ (Variables) និង logic ដំណើរការ (Functions) ស្ថិតនៅដាច់ដោយឡែកពីគ្នា ដែលធ្វើឱ្យកូដពិបាកថែទាំ ងាយកើត Bug ពេល System រីកធំ (Spaghetti Code)។
• Object-Oriented Programming (OOP): គឺជាស្ថាបត្យកម្មសរសេរកូដដែលចម្លងតាម **ពិភពពិត (Real-world Modeling)** ដោយចងភ្ជាប់ **ទិន្នន័យ (Properties)** និង **សកម្មភាព (Methods)** ឱ្យស្ថិតនៅក្នុងកញ្ចប់តែមួយ ហៅថា **Object**។
ខ. តារាងប្រៀបធៀបលក្ខណៈបច្ចេកទេស (Paradigm Comparison Table)៖
លក្ខណៈ (Feature) Procedural Programming Object-Oriented Programming (OOP)
ការផ្តោតសំខាន់ (Focus) ផ្តោតលើ **Functions & Algorithms** ផ្តោតលើ **Objects & Data Structures**
រចនាសម្ព័ន្ធទិន្នន័យ ទិន្នន័យ និង Functions នៅដាច់ដោយឡែកពីគ្នា ចងភ្ជាប់ Data និង Behavior ចូលគ្នាក្នុង **Class**
ការប្រើកូដឡើងវិញ (Reusability) ទាប (ត្រូវ Copy-Paste កូដច្រើន) ខ្ពស់ខ្លាំង (តាមរយៈ Class, Objects & Inheritance)
ភាពងាយស្រួលថែទាំ (Maintenance) ពិបាកខ្លាំងពេល Project ធំ (Spaghetti) ងាយស្រួល បំបែកជា Modules ច្បាស់លាស់
គ. កូដប្រៀបធៀប (Procedural vs OOP Comparison Code)៖
procedural_vs_oop.php
<?php
// --- 1. PROCEDURAL APPROACH (ទិន្នន័យ និង Function នៅដាច់ពីគ្នា) ---
$student_name = "សុខ ជា";
$student_score = 85.5;

function printStudentInfo(string $name, float $score): void {
    echo "[Procedural] និស្សិត៖ {$name} | ពិន្ទុ៖ {$score}<br>";
}
printStudentInfo($student_name, $student_score);

// --- 2. OBJECT-ORIENTED APPROACH (OOP - ចង Data & Function ក្នុង Class) ---
class Student {
    public string $name;
    public float $score;

    public function getDetails(): string {
        return "[OOP] និស្សិត៖ {$this->name} | ពិន្ទុ៖ {$this->score}";
    }
}

$st1 = new Student();
$st1->name = "កែវ ណារ៉ា";
$st1->score = 92.0;
echo $st1->getDetails();
?>

៥.២.១ Class Definition & `new` Operator C1 C3

ក. និយមន័យ (Definition)៖
• Class (ប្លង់មេ / Blueprint)៖ គឺជាគំរូដើមដែលកំណត់រចនាសម្ព័ន្ធទិន្នន័យ (Properties) និងសមត្ថភាពធ្វើការ (Methods)។ Class មិនទាន់យកលំហ Memory មកប្រើប្រាស់នៅឡើយទេ។
• Object (វត្ថុពិត / Instance)៖ គឺជា Concrete Entity ដែលត្រូវបានបង្កើតចេញពី Class ដោយប្រើប្រាស់ពាក្យគន្លឹះ new (ដំណើរការនេះហៅថា **Instantiation**)។ Object នីមួយៗរក្សាទុកទិន្នន័យរៀងៗខ្លួនក្នុង Memory។
ខ. ទម្រង់ទូទៅ (General Syntax)៖
// 1. Class Declaration (PascalCase Naming Convention) class ClassName { // Properties and Methods } // 2. Object Instantiation $objectInstance = new ClassName();
គ. កូដ PHP ពេញលេញ (Full PHP Code)៖
class_and_object.php
<?php
// ប្រកាស Class ឈ្មោះ Car (PascalCase)
class Car {
    public string $brand;
    public string $color;
}

// បង្កើត Object ទី១ ចេញពី Class Car
$car1 = new Car();
$car1->brand = "Toyota Prius";
$car1->color = "White";

// បង្កើត Object ទី២ ដាច់ដោយឡែកក្នុង Memory
$car2 = new Car();
$car2->brand = "Lexus RX350";
$car2->color = "Black";

echo "រថយន្តទី១៖ " . $car1->brand . " (" . $car1->color . ")<br>";
echo "រថយន្តទី២៖ " . $car2->brand . " (" . $car2->color . ")";
?>

• PascalCase Naming: ឈ្មោះ Class ត្រូវតែសរសេរជា **PascalCase** (ឧទាហរណ៍៖ StudentManager, ProductController)។

៥.៣.១ Typed Properties & Instance Methods C3

ក. និយមន័យ (Definition)៖
• Properties (អថេរថ្នាក់)៖ គឺជាអថេរដែលប្រកាសខាងក្នុង Class សម្រាប់រក្សាទុកស្ថានភាព (State/Attributes) របស់ Object។ ចាប់ពី PHP 7.4+ យើងអាចប្រកាស **Typed Properties** (ដូចជា public string $name;) ដើម្បីធានា Data Type សុវត្ថិភាព។
• Methods (អនុគមន៍ថ្នាក់)៖ គឺជា Functions ដែលប្រកាសខាងក្នុង Class សម្រាប់អនុវត្តសកម្មភាព ឬគណនាតក្កវិទ្យា (Behavior) របស់ Object។
ខ. ទម្រង់ទូទៅ (General Syntax)៖
class ClassName { public DataType $propertyName; // Typed Property public function methodName(DataType $param): ReturnType { // Method logic } }
គ. កូដ PHP ពេញលេញ (Full PHP Code)៖
typed_properties_methods.php
<?php
class BankAccount {
    public string $accountNumber;
    public float $balance = 0.0; // Default initial value

    public function deposit(float $amount): void {
        $this->balance += $amount;
    }
}

$acc = new BankAccount();
$acc->accountNumber = "AU-8899-001";
$acc->deposit(150.50);
$acc->deposit(50.00);

echo "គណនី៖ {$acc->accountNumber} | សល់ប្រាក់សរុប៖ {$acc->balance} $";
?>

Output

៥.៣.២ Pseudo-Variable `$this` & Internal Calls C4

ក. និយមន័យ (Definition)៖
`$this` គឺជា Pseudo-variable ពិសេសមួយក្នុង PHP OOP ដែលតំណាងឱ្យ **Current Object Instance** (វត្ថុបច្ចុប្បន្នដែលកំពុងត្រូវបានប្រតិបត្តិ)។ យើងប្រើ $this->propertyName ឬ $this->methodName() ដើម្បីចូលប្រើប្រាស់ Properties ឬ Methods ផ្សេងទៀតនៅក្នុង Class ជាមួយគ្នានោះ។
ខ. កូដ PHP ពេញលេញ (Full PHP Code)៖
this_keyword_demo.php
<?php
class StudentEvaluator {
    public string $name;
    public float $score;

    public function calculateGrade(): string {
        // ប្រើ $this ដើម្បីអានតម្លៃ score របស់ Instance បច្ចុប្បន្ន
        if ($this->score >= 85.0) return "A";
        if ($this->score >= 70.0) return "B";
        return "C";
    }

    public function getSummary(): string {
        // ហៅ Method calculateGrade() ផ្ទៃក្នុងតាមរយៈ $this
        $grade = $this->calculateGrade();
        return "និស្សិត៖ {$this->name} | ពិន្ទុ៖ {$this->score} | និទ្ទេស៖ {$grade}";
    }
}

$eval = new StudentEvaluator();
$eval->name = "លី ម៉េង";
$eval->score = 88.5;
echo $eval->getSummary();
?>
Output
និស្សិត៖ លី ម៉េង | ពិន្ទុ៖ 88.5 | និទ្ទេស៖ A

៥.៤.១ Constructor Property Promotion, Readonly & Named Arguments C4 C6

ក. និយមន័យ (Definition)៖
PHP 8 បានណែនាំនូវ Syntactic Sugar និងសមត្ថភាពទំនើបៗជាច្រើនដើម្បីកាត់បន្ថយ Boilerplate Code៖
  • Constructor Property Promotion: អនុញ្ញាតឱ្យយើងប្រកាស Properties និងទទួល Parameters ក្នុង __construct() ក្នុងពេលតែមួយ ដោយមិនបាច់សរសេរ $this->prop = $prop ស្ទួនដដែលៗឡើយ!
  • Readonly Properties (PHP 8.1+): កំណត់ Property ឱ្យអាចសរសេរតម្លៃបានតែ **១ ដងគត់** (ពេល Initialize) ការពារការកែប្រែ Mutation ដោយអចេតនា។
  • Named Arguments: ផ្ញើ Parameters ទៅកាន់ Constructor/Method ដោយបញ្ជាក់ឈ្មោះ parameter ផ្ទាល់ មិនបាច់ខ្វល់ពីលំដាប់លំដោយ។
ខ. កូដប្រៀបធៀប (PHP 7 Traditional vs PHP 8 Promotion)៖
php8_constructor_promotion.php
<?php
declare(strict_types=1);

// =========================================================
// PHP 8 MODERN CLASS: Constructor Promotion + Readonly
// =========================================================
class Product {
    public function __construct(
        public readonly int $id,
        public string $title,
        public float $price = 0.0,
        public int $stock = 10
    ) {}

    public function getFormattedPrice(): string {
        return number_format($this->price, 2) . " $";
    }
}

// ប្រើប្រាស់ PHP 8 Named Arguments ពេល Instantiate Object
$item = new Product(
    title: "Dell XPS 15 Laptop",
    price: 1250.00,
    id: 101
);

echo "ID: {$item->id} | ទំនិញ៖ {$item->title} | តម្លៃ៖ " . $item->getFormattedPrice();
?>

    public function __construct(
        public readonly string $studentId,
