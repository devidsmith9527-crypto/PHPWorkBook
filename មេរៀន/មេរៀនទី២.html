ក. និយមន័យ និងការបកស្រាយ (Definition & Explanation)៖
PHP Tags គឺជាសញ្ញាសម្គាល់ (Delimiters) ដែលប្រាប់ Apache/Nginx Web Server និង PHP Processing Engine ឱ្យដឹងថាតើផ្នែកណាជាកូដ PHP ដែលត្រូវប្រកាសប្រតិបត្តិ (Execute) និងផ្នែកណាជា HTML ធម្មតា។
  • Standard Tag (<?php ... ?>)៖ ជាទម្រង់ស្តង់ដារដែលត្រូវបានណែនាំឱ្យប្រើប្រាស់ដាច់ខាត ព្រោះវាដំណើរការបាននៅលើគ្រប់ Apache Server ទាំងអស់ដោយគ្មានបញ្ហា។
  • Short Echo Tag (<?= ... ?>)៖ ប្រើសម្រាប់បង្ហាញតម្លៃអថេរ ឬ Expression ភ្លាមៗនៅក្នុង HTML Template (ស្មើនឹង <?php echo ... ?>)។ វាត្រូវបានបើកដំណើរការជានិច្ចចាប់ពី PHP 5.4 ឡើងទៅ។
  • Short Open Tag (<? ... ?>)៖ ត្រូវការកំណត់ short_open_tag = On នៅក្នុងឯកសារ Configuration php.ini របស់ Apache Server។ ការប្រើប្រាស់វាអាចបង្កជម្លោះ (Conflict) ជាមួយ XML Syntax ដូច្នេះមិនត្រូវបានណែនាំឡើយ។
តារាងប្រៀបធៀប PHP Tags & php.ini Directives:
ប្រភេទ Tag ទម្រង់ Syntax php.ini Requirement កម្រិតអនុសាសន៍ (Recommendation)
Standard Tag<?php ... ?>គ្មាន (ដំណើរការបានគ្រប់ Server)ណែនាំខ្ពស់បំផុត (Standard)

ក. និយមន័យ (Definition)៖
Comments គឺជាផ្នែកនៃកូដដែល PHP Processing Engine មើលរំលងមិនប្រកាសប្រតិបត្តិឡើយ។ វាមានសារប្រយោជន៍ក្នុងការកត់សម្គាល់ការពន្យល់ និងបង្កើនភាពងាយស្រួលអានកូដ (Readability)។ PHP គាំទ្រ Comments ៣ ប្រភេទ៖
  1. Single-line Comment: ប្រើសញ្ញា // ឬ # (Unix Shell Style) សម្រាប់កត់សម្គាល់ ១ បន្ទាត់។
  2. Multi-line Comment: ប្រើសញ្ញា /* ... */ សម្រាប់កត់សម្គាល់ច្រើនបន្ទាត់។
  3. DocBlock Comment: ប្រើសញ្ញា /** ... */ សម្រាប់សរសេរឯកសារកូដ (Documentation/PHPDoc) សម្រាប់ Functions, Classes, និង Methods។

៣.២.២ ដែនកំណត់អថេរ (Variable Scope: Local, Global, Static) C3

ក. និយមន័យ (Definition)៖
Variable Scope គឺជាដែនកំណត់ដែលអថេរអាចត្រូវបានចូលប្រើប្រាស់បានក្នុងកម្មវិធី៖
  • Local Scope: អថេរដែលប្រកាសក្នុង Function អាចប្រើបានតែក្នុង Function នោះប៉ុណ្ណោះ។
  • Global Scope: អថេរប្រកាសក្រៅ Function។ ដើម្បីប្រើក្នុង Function ត្រូវប្រើពាក្យគន្លឹះ global ឬ Array $GLOBALS[]។
  • Static Scope: អថេរប្រកាសដោយពាក្យគន្លឹះ static ក្នុង Function ដែលរក្សាតម្លៃក្នុង Memory មិនឱ្យបាត់បង់ឡើយទោះបីជា Function ត្រូវបានបញ្ចប់ការប្រតិបត្តិក៏ដោយ។

ក. និយមន័យ (Definition)៖
Constant (ថេរ) គឺជា Identifier សម្រាប់រក្សាទុកតម្លៃដែលមិនអាចប្រែប្រួលបាន (Immutable) ក្រោយពេលកំណត់រួច។ define() កំណត់ Constant ពេល Run-time ឯ const កំណត់ពេល Compile-time។ Magic Constants (ដូចជា __DIR__, __FILE__, __LINE__) ប្រកាសតម្លៃប្រែប្រួលតាមបរិបទកូដ។
ខ. ទម្រង់ទូទៅ (General Syntax)៖
define("CONSTANT_NAME", value); const CONSTANT_NAME = value;
គ. កូដ PHP ពេញលេញ (Complete Code)៖
constants_demo.php
<?php
define("SITE_URL", "https://au.edu.kh");

?>
ឃ. លទ្ធផល (Execution Output)៖
Output
URL: https://au.edu.kh | DB: db_angkor_univ | File: /var/www/constants_demo.php

៣.៧.១ while Loop C4

ក. និយមន័យ (Definition)៖
while Loop ផ្ទៀងផ្ទាត់លក្ខខណ្ឌមុន រួចប្រតិបត្តិកូដ។ កូដដំណើរការរហូតទាល់តែលក្ខខណ្ឌក្លាយជា False។
ខ. ទម្រង់ទូទៅ (General Syntax)៖
while (condition) { // Code block to execute }
គ. កូដ PHP ពេញលេញ (Complete Code)៖
loop_while.php
<?php
$i = 1;
while ($i <= 3) {
    echo "Count: {$i}<br>";
    $i++;
}
?>
ឃ. លទ្ធផល (Execution Output)៖
Output
Count: 1
Count: 2
Count: 3

៣.៧.៣ for Loop C4

ក. និយមន័យ (Definition)៖
for Loop ប្រើប្រាស់នៅពេលដឹងចំនួនជុំ (Iterations) ច្បាស់លាស់ ដោយមាន init, condition, និង increment ក្នុងបន្ទាត់តែមួយ។
ខ. ទម្រង់ទូទៅ (General Syntax)៖
for ($i = 0; $i < $count; $i++) { ... }
គ. កូដ PHP ពេញលេញ (Complete Code)៖
loop_for.php
<?php
for ($i = 1; $i <= 3; $i++) { echo "Item #{$i}<br>"; }
?>
ឃ. លទ្ធផល (Execution Output)៖
Output
Item #1
Item #2
Item #3

៣.៧.៤ foreach Loop C6

ក. និយមន័យ (Definition)៖
foreach Loop ប្រើប្រាស់យ៉ាងពិសេសសម្រាប់ទាញ Element / Key ពី Array ឬ Object ដោយស្វ័យប្រវត្តិ។
ខ. ទម្រង់ទូទៅ (General Syntax)៖
foreach ($array as $key => $value) { ... }
គ. កូដ PHP ពេញលេញ (Complete Code)៖
loop_foreach.php
<?php
$user = ["name" => "Sok", "role" => "Admin"];
foreach ($user as $k => $v) { echo "{$k}: {$v}<br>"; }
?>
ឃ. លទ្ធផល (Execution Output)៖
Output
name: Sok
role: Admin
