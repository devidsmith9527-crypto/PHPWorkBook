[Two-Phase Execution Architecture in PDO] Step 1 (Compile Phase): PHP -> $pdo->prepare("SELECT * FROM tbl_products WHERE pcode = :code") ==> Database Server ធ្វើការ Pre-compile និង Parse វេយ្យាករណ៍ជាមុន។ Step 2 (Execute Phase): PHP -> $stmt->execute([':code' => $userInput]) ==> Database ចាត់ទុក $userInput ជា Literal Value (តម្លៃសុទ្ធ) មិនអាចក្លាយជាកូដ SQL បានឡើយ!

ការបំបែក Code & Data ច្របូកច្របល់គ្នាជា String តែមួយ បំបែកដាច់ដោយឡែកពីគ្នាជា ២ ដំណាក់កាល
