  • ជំហានទី ១ (Session Initialization)៖ បើកដំណើរការ session_start() នៅផ្នែកលើបង្អស់នៃឯកសារ Middleware។

  • $_SESSION = []; (សម្អាត Array នៃ Session Memory)
  • setcookie(session_name(), '', time() - 42000, '/'); (លុប Session Cookie ចេញពី Browser)

ក. មហន្តរាយនៃការរក្សាទុក Password ជា Plain Text (The Plain-Text Disaster)៖
ការរក្សាទុកលេខសម្ងាត់របស់អ្នកប្រើប្រាស់ជាអក្សរច្បាស់ៗ (Plain Text ដូចជា "123456") ក្នុង Database គឺជាកំហុសវិជ្ជាជីវៈកម្រិតធ្ងន់ធ្ងរបំផុត។ ប្រសិនបើ Database ត្រូវបានលួចដោយ Hacker (តាមរយៈ SQL Injection ឬ Data Breach) គណនីរបស់អ្នកប្រើទាំងអស់នឹងត្រូវលេចធ្លាយភ្លាមៗ។
ខ. ការប្រៀបធៀបជាមូលដ្ឋានរវាង Hashing, Encryption និង Encoding៖
  • Encoding (ឧ. Base64)៖ បំប្លែងទម្រង់ទិន្នន័យដើម្បីងាយស្រួលបញ្ជូនតាមបណ្តាញ។ គ្មានសុវត្ថិភាពទាល់តែសោះ ព្រោះនរណាក៏អាច Decode ត្រឡប់មកវិញបាន។
  • Encryption (ឧ. AES-256)៖ ជាអនុគមន៍ ពីទិស (Two-Way Function) ដែលប្រើ Secret Key ដើម្បី Lock និង Unlock។ ស័ក្តិសមសម្រាប់ទិន្នន័យដែលត្រូវការអានឡើងវិញ (ដូចជាលេខកាតធនាគារ)។
  • Hashing (ឧ. Bcrypt / Argon2)៖ ជាអនុគមន៍គណិតវិទ្យា មួយទិស (One-Way Cryptographic Function)។ មានន័យថា ទោះបីជាស្គាល់ Hash String ក៏គ្មានវិធីសាស្ត្រគណិតវិទ្យាណាអាច Decode ត្រឡប់ទៅជា Password ដើមបានឡើយ!
