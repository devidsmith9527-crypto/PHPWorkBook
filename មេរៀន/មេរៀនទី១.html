៣.១.១ ស្ថាបត្យកម្ម 3-Tier Web Architecture C1

ក. និយមន័យ (Definition)៖
Web Application ដំណើរការលើស្ថាបត្យកម្ម 3-Tier ៖
  • Presentation Tier (Client Side): ដំណើរការលើ Web Browser ( HTML5, CSS3, JavaScript) បង្ហាញ UI/UX។
  • Application Tier (Server Side): ដំណើរការដោយ Apache Web Server () និង PHP 8 Engine () គណនា Business Logic។
  • Data Tier (Database Layer): គ្រប់គ្រងដោយ MySQL 8 RDBMS () រក្សាទុកទិន្នន័យប្រព័ន្ធ។

៣.១.២ ដំណើរការ Client-Side Script ធៀបនឹង Server-Side Script C2

ក. ការប្រៀបធៀបទីតាំង និងដំណើរការប្រតិបត្តិ (Execution Comparison)៖
លក្ខណៈប្រៀបធៀប Client-Side Scripting ( JavaScript) Server-Side Scripting ( PHP)
ទីតាំង Execute ដំណើរការលើ Web Browser របស់ User ផ្ទាល់ (Client's CPU/RAM)។ ដំណើរការលើ Web Server Machine ជាមុនសិន រួចទើបបាញ់ HTML មក Client។
ការមើលឃើញកូដ User អាចមើលឃើញ Source Code ទាំងអស់តាម Inspect Element/View Source។ User មិនអាច មើលឃើញកូដ PHP ឡើយ (ឃើញតែ HTML Output ដែល PHP បញ្ចេញ)។
តួនាទីចម្បង បង្កើត UI Interactivity, DOM Animations, ផ្ទៀងផ្ទាត់ Form ភ្លាមៗ (Instant Validation)។ គណនា Business Logic, ទាក់ទង Database, គ្រប់គ្រង Sessions/Security, ផ្ទុក File Uploads។

៣.១.៣ HTTP Protocol, Methods & Status Codes C2

• HTTP Methods: GET (ទាញយកទិន្នន័យ, បង្ហាញ params លើ URL) និង POST (បញ្ជូនទិន្នន័យសម្ងាត់ក្នុង Request Body)។
• HTTP Status Codes: 200 OK (ជោគជ័យ), 301/302 Redirect (ប្តូរទិស), 404 Not Found (រកមិនឃើញ File), និង 500 Internal Error (កូដ PHP មាន Syntax Error)។

ក. និយមន័យ និងតួនាទី (Definition & Role)៖
Apache HTTP Server () គឺជា Open-source Web Server ដើរតួជាអ្នករង់ចាំស្តាប់ Request (Port 80/443) ពី Browser។ ប្រសិនបើ Request សុំ File .html/.css/.png នោះ Apache បញ្ជូនទៅ Browser ភ្លាមៗ។ ប៉ុន្តែបើ Request សុំ File .php នោះ Apache បាញ់ឯកសារទៅឱ្យ PHP Engine ដំណើរការជាមុនសិន។

៣.២.២ តើ PHP 8 ជាអ្វី? ហេតុអ្វីត្រូវសិក្សាវា? C2

ក. និយមន័យ (Definition)៖
PHP (អក្សរកាត់ Recursive មកពី Hypertext Preprocessor) គឺជាភាសាសរសេរកូដប្រភេទ Server-Side Scripting Language ប្រភពបើកចំហរ (Open-Source) ដែលត្រូវបង្កើតឡើងដោយលោក Rasmus Lerdorf ក្នុងឆ្នាំ ១៩៩៤។ ជំនាន់ PHP 8 ត្រូវបានបំពាក់នូវ JIT (Just-In-Time) Compiler បង្កើនល្បឿន និងសមត្ថភាពគណនាខ្ពស់បំផុត។
ខ. មូលហេតុចម្បងៗទាំង ៥ ក្នុងការសិក្សា PHP 8 (Why Study PHP 8?)៖
  1. Dominance on the Web: PHP គ្រប់គ្រង និងដំណើរការលើសពី **៧៥%** នៃគេហទំព័រទូទាំងពិភពលោក (រួមទាំង WordPress, Wikipedia, Drupal)។
  2. Easy Learning Curve & High Productivity: មាន Syntax ងាយស្រួលរៀន សមស្របបំផុតសម្រាប់និស្សិតចាប់ផ្តើមគ្រឹះ Web Development។
  3. Modern PHP 8 Features: មាន JIT Compiler, Match Expressions, Named Arguments, Union Types និង Strict Type Hinting ដែលមានសុវត្ថិភាពខ្ពស់។
  4. Foundation for Modern Frameworks: ជាគ្រឹះមិនអាចខ្វះបានសម្រាប់ឈានទៅសិក្សា **Laravel Framework** ខ្នាត Enterprise ក្នុងវគ្គបន្ទាប់។
  5. Job Demand & Ecosystem: មានទីផ្សារការងារខ្ពស់ និង Ecosystem ធំទូលាយ (Composer, Packagist)។

៨.ឃ. ចម្លើយសំណួរបកស្រាយ (Answers to Explanatory Questions Q7.1 - Q7.9 ឆ្លើយម្ដងមួយតាមលំដាប់)
• ចម្លើយ Q7.1 (Client-Side vs Server-Side Scripting)៖
Client-Side Scripting (JS) ដំណើរការកូដដោយផ្ទាល់លើ Web Browser របស់អ្នកប្រើប្រាស់ ប្រើសម្រាប់បង្កើត UI Interactivity និងមើលឃើញកូដដើមបាន។ ឯ Server-Side Scripting (PHP) ដំណើរការកូដលើ Web Server ប្រើសម្រាប់គណនា Business Logic, ទាក់ទង Database និងបង្កើតទំព័រ HTML បញ្ជូនមក Client ដោយលាក់បាំងកូដដើម។
• ចម្លើយ Q7.2 (htdocs Directory Role & Path)៖
Folder htdocs គឺជា Root Web Directory របស់ Apache Web Server ក្នុង XAMPP (File Path: C:\xampp\htdocs\)។ រាល់ Project PHP ទាំងអស់ត្រូវតែដាក់ក្នុង Folder នេះ ទើប Web Server អាចស្គាល់ និង Map ទៅជា URL Address http://localhost/project_name/ លើ Browser បាន។
• ចម្លើយ Q7.3 (PHP Tags Purpose)៖
<?php គឺជា Opening Tag និង ?> គឺជា Closing Tag។ ពួកវាមានតួនាទីជា Delimiters ប្រាប់ទៅ Web Server Apache ថា អត្ថបទ ឬកូដដែលស្ថិតនៅចន្លោះ Tag ទាំងពីរនេះ គឺជាកូដ PHP ដែលត្រូវបញ្ជូនទៅឱ្យ PHP Engine ធ្វើការ Compile/Execute ជាមុនសិន។
• ចម្លើយ Q7.4 (HTTP Request-Response Lifecycle)៖
(1) User វាយ URL លើ Browser ➔ (2) Browser បាញ់ HTTP Request ទៅ Apache Web Server ➔ (3) Apache ឃើញ Extension .php បញ្ជូនទៅ PHP Engine ➔ (4) PHP Execute កូដ (និងសួររក MySQL បើមាន) ➔ (5) PHP បំប្លែងលទ្ធផលជា HTML សុទ្ធ ➔ (6) Apache បាញ់ HTTP Response (HTML) ត្រឡប់មក Browser ដើម្បី Render បង្ហាញ UI។
• ចម្លើយ Q7.5 (Why Cannot Double-click .php Files)៖
ដោយសារ Browser គ្មាន PHP Engine សម្រាប់ Compile កូដ PHP ឡើយ។ បើ Double-click បើក វានឹងប្រើ Protocol file:/// នាំឱ្យ Browser បង្ហាញកូដ PHP ដើមមកក្រៅ។ ឯកសារ PHP ត្រូវតែរត់តាម Protocol http://localhost/ ដើម្បីឱ្យ Apache Web Server ចាត់ចែង។
