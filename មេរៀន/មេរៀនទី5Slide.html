សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY

Procedural Approach

៥.២.១ និយមន័យ Class និង Object (Blueprint vs. Instance)

Core OOP Concepts: Architectural Blueprints and Concrete In-Memory Instances

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY

C1 ១. ថ្នាក់ (Class / Blueprint)

គឺជាប្លង់មេ (Blueprint) ឬគំរូដើមដែលកំណត់រចនាសម្ព័ន្ធទិន្នន័យ (Properties) និងសមត្ថភាពធ្វើការ (Methods)។

  • Class ប្រៀបដូចជា ប្លង់សាងសង់ផ្ទះ។
  • វាមិនទាន់យកលំហ Memory មកប្រើប្រាស់ជាក់ស្តែងនៅឡើយទេ។
  • ឈ្មោះ Class ត្រូវសរសេរតាមស្តង់ដារ PascalCase។

C1 ២. វត្ថុ (Object / Instance)

គឺជាវត្ថុពិតជាក់ស្តែង (Concrete Instance) ដែលត្រូវបានបង្កើតចេញពី Class។

  • Object ប្រៀបដូចជា ផ្ទះពិតប្រាកដដែលសាងសង់រួច។
  • វាត្រូវបានបង្កើតតាមរយៈពាក្យគន្លឹះ new (ហៅថា Instantiation)។
  • Object នីមួយៗកាន់កាប់លំហ Memory រៀងៗខ្លួន។

Declaration Syntax, Instantiation, and the Member Access Operator (->)

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY

C3 ទម្រង់ទូទៅ (General Syntax)

// 1. Class Declaration (PascalCase) class ClassName { // Properties and Methods } // 2. Object Instantiation $objectInstance = new ClassName(); // 3. Property Access (No $ sign after ->) $objectInstance->propertyName = "Value";

💡 ច្បាប់ចងចាំ ៖ ពេលចូលប្រើ Property តាម Single Arrow (->) គឺ មិនបាច់ដាក់សញ្ញា $ ពីមុខឈ្មោះ Property ឡើយ! (ឧ. $car->brand មិនមែន $car->$brand ទេ)។

កូដ PHP អនុវត្តជាក់ស្តែង

<?php class Car { public string $brand; public string $color; } // Instantiation: បង្កើត Object ពីរដាច់ពីគ្នា $car1 = new Car(); $car1->$brand = "Toyota Prius"; $car1->$color = "White"; $car2 = new Car(); $car2->$brand = "Lexus RX350"; $car2->$color = "Black"; echo "រថយន្តទី១៖ {$car1->brand} ({$car1->color})<br>"; echo "រថយន្តទី២៖ {$car2->brand} ({$car2->color})"; ?>
រថយន្តទី១៖ Toyota Prius (White) រថយន្តទី២៖ Lexus RX350 (Black)

៥.៣.១ Properties និង Methods ក្នុង Class

State and Behavior: Declaring Strongly Typed Attributes and Class Functions

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY

C2 Typed Properties (អថេរថ្នាក់)

ជាអថេរប្រកាសក្នុង Class សម្រាប់រក្សាទុកស្ថានភាព (State/Data)។ ចាប់ពី PHP 7.4+ យើងអាចកំណត់ Type ជាក់លាក់ ៖

public string $accountNumber; public float $balance = 0.0; // Default Value

ជួយឱ្យប្រព័ន្ធទប់ស្កាត់ការបញ្ចូល Data Type ខុសដោយស្វ័យប្រវត្តិ (Type Safety)។

C3 Instance Methods (អនុគមន៍ថ្នាក់)

ជា Functions ដែលប្រកាសក្នុង Class សម្រាប់អនុវត្តសកម្មភាព ឬតក្កវិទ្យា (Behavior/Action) ៖

public function deposit(float $amount): void { $this->balance += $amount; }

អាចទទួល Parameters និងបញ្ជូន Return Values ដូច Functions ធម្មតាដែរ។

ការអនុវត្ត Properties & Methods ជាក់ស្តែង

Real-World Example: BankAccount Class with State Mutation and Methods

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY

BankAccount Class

<?php class BankAccount { public string $accountNumber; public float $balance = 0.0; public function deposit(float $amount): void { $this->balance += $amount; } public function withdraw(float $amount): bool { if ($amount <= $this->balance) { $this->balance -= $amount; return true; } return false; } } ?>

ការប្រតិបត្តិលើ Object

C4 Lab 5.6 (Bank Account)

<?php class BankAccount { public float $balance = 0.0; public function deposit(float $amt): void { $this->balance += $amt; } public function withdraw(float $amt): bool { if ($amt <= $this->balance) { $this->balance -= $amt; return true; } return false; } } $b = new BankAccount(); $b->deposit(100); $b->withdraw(30); echo "សល់៖ {$b->balance} $"; ?>
សល់៖ 70 $
