១. ការពិពណ៌នាមុខវិជ្ជា (Course Description)
មុខវិជ្ជានេះត្រូវបានរចនាឡើងយ៉ាងពិសេសដើម្បីបំពាក់ជំនាញដល់និស្សិតក្នុងការអភិវឌ្ឍកម្មវិធីវិប (Web Application) ទំនើប និងមានសុវត្ថិភាពខ្ពស់ ក្នុងរយៈពេល ៤៥ម៉ោង។ នៅក្នុងយុគសម័យឌីជីថលដែលទាមទារនូវប្រព័ន្ធមានលំនឹង និងងាយស្រួលថែទាំ មុខវិជ្ជានេះនឹងដើរតួនាទីជាស្ពានចម្លងដ៏សំខាន់ដោយតម្រង់ទិសការគិតរបស់និស្សិតពីការសរសេរកូដបែប Procedural ធម្មតា ទៅកាន់ស្ថាបត្យកម្ម OOP (Object-Oriented Programming) ដែលជាគ្រឹះមិនអាចខ្វះបានសម្រាប់ឈានទៅសិក្សា Frameworks ខ្នាតធំ (ដូចជា Laravel Framework នៅក្នុងវគ្គបន្ទាប់)។
ក្នុងអំឡុងពេលសិក្សា និស្សិតនឹងទទួលបានចំណេះដឹងស៊ីជម្រៅលើការប្រើប្រាស់ PHP (Hypertext Preprocessor) 8 និងប្រព័ន្ធគ្រប់គ្រងមូលដ្ឋានទិន្នន័យ MySQL (My Structured Query Language) RDBMS (Relational Database Management System)។ លើសពីនេះទៅទៀត មុខវិជ្ជានេះសង្កត់ធ្ងន់យ៉ាងខ្លាំងទៅលើផ្នែកសន្តិសុខវិប Web Security។ និស្សិតនឹងត្រូវបានតម្រូវឱ្យ អនុវត្ត ការភ្ជាប់ទិន្នន័យតាមរយៈ PDO (PHP Data Objects) ជំនួសឲ្យការប្រើប្រាស់ MySQLi ចាស់ៗ ដើម្បី ទប់ស្កាត់ ការវាយប្រហារតាមរយៈ SQL (Structured Query Language) Injection។
និស្សិតក៏នឹងបាន អភិវឌ្ឍ មុខងារប្រតិបត្តិការគោលទាំង៤ CRUD (Create, Read, Update, Delete), បង្កើត ប្រព័ន្ធគ្រប់គ្រងគណនីអ្នកប្រើប្រាស់ (Authentication / Login) ប្រកបដោយសុវត្ថិភាពតាមរយៈ Password Hashing, និង ប្រើប្រាស់ ឧបករណ៍ Git / GitHub ដើម្បីគ្រប់គ្រងកំណែកូដ (Version Control System) និងធ្វើការជាក្រុមយ៉ាងមានប្រសិទ្ធភាព។
សទ្ទានុក្រម និងពាក្យគន្លឹះ (Key Terms)

OOP (Object-Oriented Programming)

ទម្រង់សរសេរកូដប្រើប្រាស់ Class និង Object ធ្វើឲ្យកូដមានរបៀប ងាយថែទាំ និងអាចប្រើប្រាស់ឡើងវិញបាន។

PDO (PHP Data Objects)

បច្ចេកវិទ្យាតភ្ជាប់ Database របស់ PHP ដែលគាំទ្រ RDBMS ច្រើនប្រភេទ និងមានសុវត្ថិភាពខ្ពស់។

SQL Injection & XSS (Cross-Site Scripting)

ប្រភេទនៃការវាយប្រហារដ៏គ្រោះថ្នាក់លើ Web ដែល PDO Prepared Statements អាចជួយទប់ស្កាត់បាន។

Version Control System (Git / GitHub)

ប្រព័ន្ធសម្រាប់រក្សាទុកប្រវត្តិនៃការកែប្រែកូដ និងអនុញ្ញាតឲ្យអ្នកអភិវឌ្ឍន៍ច្រើននាក់ធ្វើការលើគម្រោងតែមួយ។

១ វត្តមាន និងការចូលរួម (Attendance) ១០% អនុវត្ត កូដក្នុងថ្នាក់ និងចូលរួមសកម្មភាពដោះស្រាយបញ្ហា (CLO 1, CLO 2)។
២ កិច្ចការផ្ទះ និងស្រាវជ្រាវ (HW & Assignment) ៣០% អភិវឌ្ឍ គម្រោងខ្នាតតូច, ប្រើប្រាស់ GitHub និង ធ្វើបទបង្ហាញ (CLO 3, CLO 5)។
៣ ប្រឡងពាក់កណ្តាលឆមាស (Mid-Term Exam) ២០% បកស្រាយ និង សរសេរ កូដ PHP មូលដ្ឋាន, OOP និងការប្រើ Form (CLO 2, CLO 3)។
៤ ប្រឡងបញ្ចប់ឆមាស (Final Exam) ៤០% បង្កើត ប្រព័ន្ធ Web CRUD ភ្ជាប់ MySQL តាមរយៈ PDO ពេញលេញ (CLO 4, CLO 5)។

៦.១- រង្វាយតម្លៃលើវត្តមាន និងការចូលរួម
