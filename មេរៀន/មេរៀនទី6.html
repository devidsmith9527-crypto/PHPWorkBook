៦.១.១ និយមន័យ Encapsulation & Visibility Matrix Table C2

ក. និយមន័យ (Definition)៖
• Encapsulation (ការខ្ចប់ និងលាក់ទិន្នន័យ)៖ គឺជាសសរទ្រូងទី១ នៃ OOP ដែលធ្វើការខ្ចប់ Data (Properties) និង Operations (Methods) ចូលគ្នាក្នុង Class តែមួយ ព្រមទាំង **លាក់បាំងបដិសេធ (Data Hiding)** ការចូលប្រើប្រាស់ទិន្នន័យសំខាន់ៗដោយផ្ទាល់ពីខាងក្រៅ Class (External Scope) ដើម្បីការពារ Data Corruption។
• Access Modifiers (កម្រិតសិទ្ធិមើលឃើញ / Visibility)៖ ត្រូវបានប្រើប្រាស់កំណត់សិទ្ធិក្នុងការចូលប្រើ Member របស់ Class៖
ខ. តារាងប្រៀបធៀប Access Modifiers (Visibility Matrix Table)៖
Access Modifier ខាងក្នុង Class ខ្លួនឯង (Inside Same Class) ខាងក្នុង Class កូន (Subclass / Child Class) ខាងក្រៅ Class (Global / External Scope)
public ✓ អាចចូលប្រើបាន ✓ អាចចូលប្រើបាន ✓ អាចចូលប្រើបាន
protected ✓ អាចចូលប្រើបាន ✓ អាចចូលប្រើបាន ✗ បដិសេធសិទ្ធិ (Fatal Error)
private ✓ អាចចូលប្រើបាន ✗ បដិសេធសិទ្ធិ (Fatal Error) ✗ បដិសេធសិទ្ធិ (Fatal Error)
គ. កូដ PHP បង្ហាញពី Access Modifiers (Visibility Demo)៖
visibility_demo.php
<?php
class UserAccount {
    public string $username = "sok_chia";       // ចូលប្រើបានគ្រប់ទីកន្លែង
    protected string $email = "sok@au.edu.kh";  // ចូលប្រើបានតែក្នុង Class នេះ & Child Class
    private string $password = "Secret123";    // ចូលប្រើបានតែក្នុង Class នេះ ១ គត់

    public function showInternalDetails(): void {
        // ខាងក្នុង Class ខ្លួនឯង អាចអានបានទាំង public, protected & private!
        echo "User: {$this->username} | Email: {$this->email} | Pass: {$this->password}";
    }
}

$user = new UserAccount();
echo $user->username . "<br>"; // OK: public property
// echo $user->password; // FATAL ERROR: Cannot access private property UserAccount::$password!
$user->showInternalDetails();
?>

៦.២ ការគ្រប់គ្រងទិន្នន័យតាមរយៈ Getter & Setter Methods C2 C3

៦.២.១ Controlled Access & Data Validation Pipeline C3

ក. និយមន័យ (Definition)៖
ដើម្បីអនុវត្ត Encapsulation ឱ្យត្រឹមត្រូវ យើងត្រូវកំណត់ Properties សំខាន់ៗជា private ឬ protected រួចបង្កើត Public Methods ចំនួនពីរក្រុមដើម្បីគ្រប់គ្រងទិន្នន័យ៖
  • Getter Method (get...())៖ ប្រើប្រាស់សម្រាប់ **ទាញយក/អាន (Read)** តម្លៃ Property មកបង្ហាញខាងក្រៅ។
  • Setter Method (set...())៖ ប្រើប្រាស់សម្រាប់ **កំណត់/កែប្រែ (Write)** តម្លៃ Property ដោយឆ្លងកាត់ការ **Validate (ផ្ទៀងផ្ទាត់)** សុពលភាពទិន្នន័យមុននឹងរក្សាទុក ទប់ស្កាត់មិនឱ្យមានទិន្នន័យខុសច្បាប់ (ឧ. ប្រាក់សល់ $balance < 0, អាយុអវិជ្ជមាន)។
ខ. ទម្រង់ទូទៅ (General Syntax)៖
class ClassName { private DataType $property; public function getProperty(): DataType { return $this->property; } public function setProperty(DataType $val): void { // Validation Logic $this->property = $val; } }
គ. កូដ PHP ពេញលេញ (Full PHP Code)៖
getter_setter_validation.php
<?php
class BankAccount {
    private float $balance = 0.0;

    // Getter Method for Balance
    public function getBalance(): float {
        return $this->balance;
    }

    // Setter Method with Validation Pipeline
    public function deposit(float $amount): void {
        if ($amount <= 0) {
            echo "<span style='color:red;'>[Error] ចំនួនប្រាក់ផ្ញើត្រូវតែធំជាង 0 $!</span><br>";
            return;
        }
        $this->balance += $amount;
        echo "បានផ្ញើប្រាក់ចំនួន {$amount} $ ជោគជ័យ។<br>";
    }
}

$acc = new BankAccount();
$acc->deposit(-50.00); // Rejected by Setter Validation!
$acc->deposit(200.00); // Approved!
echo "ប្រាក់ក្នុងគណនីបច្ចុប្បន្ន៖ " . $acc->getBalance() . " $";
?>
ឃ. លទ្ធផលបង្ហាញ (Execution Output)៖
Output
[Error] ចំនួនប្រាក់ផ្ញើត្រូវតែធំជាង 0 $! បានផ្ញើប្រាក់ចំនួន 200 $ ជោគជ័យ។ ប្រាក់ក្នុងគណនីបច្ចុប្បន្ន៖ 200 $

• Data Integrity Guarantee: ការប្រើប្រាស់ Getter/Setter ធានាថាមិនមានកូដខាងក្រៅណាអាចលួចប្តូរ $acc->balance = -99999; បានឡើយ! គ្រប់ការកែប្រែទាំងអស់ត្រូវឆ្លងកាត់ការផ្ទៀងផ្ទាត់ (Validation Rules) ជាដាច់ខាត។

៦.៣ ស្ថាបត្យកម្ម Class Inheritance តាមរយៈពាក្យគន្លឹះ `extends` C3 C4

៦.៣.១ Parent (Base) Class & Child (Derived) Class Structure C3 C4

ក. និយមន័យ (Definition)៖
• Inheritance (ការបន្តពូជ)៖ គឺជាសសរទ្រូងទី២ នៃ OOP ដែលអនុញ្ញាតឱ្យ Class ថ្មីមួយ (**Child / Derived Class**) អាចបន្តពូជទាញយក Properties និង Methods ទាំងប៉ុន្មាន (ប្រភេទ public និង protected) ពី Class ដើម (**Parent / Base Class**) មកប្រើប្រាស់ស្វ័យប្រវត្តិ តាមរយៈពាក្យគន្លឹះ extends ដោយមិនបាច់សរសេរកូដដដែលៗឡើងវិញឡើយ (គោលការណ៍ **DRY - Don't Repeat Yourself**)!
ខ. ទម្រង់ទូទៅ (General Syntax)៖
// Parent Class Definition class ParentClass { protected DataType $property; } // Child Class Inheriting Parent Class class ChildClass extends ParentClass { // Child inherits $property and can add its own new features }
គ. កូដ PHP ពេញលេញ (Full PHP Code)៖
inheritance_demo.php
<?php
// 1. Parent Class (Base Class)
class User {
    public string $username;
    public string $email;

    public function getProfile(): string {
        return "User: {$this->username} ({$this->email})";
    }
}

// 2. Child Class Inheriting from User Class
class Admin extends User {
    public array $permissions = []; // Feature ថ្មីបន្ថែមសម្រាប់ Admin

    public function banUser(string $targetUser): void {
        echo "<span style='color:red;'>Admin {$this->username} បានគៀបសង្កត់ Ban គណនី៖ {$targetUser}!</span><br>";
    }
}

$admin = new Admin();
$admin->username = "lim_sysadmin"; // Inherited Property
$admin->email = "admin@au.edu.kh";  // Inherited Property

echo $admin->getProfile() . "<br>"; // Inherited Method
$admin->banUser("bad_user99");       // Admin Specific Method
?>

៦.៤ បច្ចេកទេស Method Overriding, `parent::` Scope & PHP 8.3 `#[\Override]` C3 C4 C6

៦.៤.១ Method Overriding & `parent::__construct()` C4 C6

ក. និយមន័យ (Definition)៖
• Method Overriding: គឺជាការសរសេរឡើងវិញ (Redefine) នូវ Method របស់ Parent Class នៅក្នុង Child Class ដើម្បីកែប្រែ ឬបន្ថែមតក្កវិទ្យាថ្មីសមស្របតាមបរិបទ Class កូន។
• `parent::` Scope Resolution Operator: ត្រូវបានប្រើប្រាស់នៅក្នុង Child Class ដើម្បី **ហៅ/រំលឹក (Invoke)** Method ដើមរបស់ Parent Class មកប្រតិបត្តិជាមុន (ជាពិសេសការហៅ parent::__construct()) ដើម្បីកាត់បន្ថយកូដស្ទួនពេលបន្តពូជ Constructor។
ខ. ទម្រង់ទូទៅ (General Syntax)៖
class ChildClass extends ParentClass { #[\Override] // PHP 8.3 Attribute public function __construct(type $parentProp, type $childProp) { parent::__construct($parentProp); // Call Parent Constructor $this->childProp = $childProp; } }
គ. កូដ PHP ពេញលេញ (Full PHP Code)៖
method_overriding_parent.php
<?php
declare(strict_types=1);

class Employee {
    public function __construct(
        public string $name,
        public float $salary
    ) {}

    public function getSalaryDetails(): string {
        return "បុគ្គលិក៖ {$this->name} | ប្រាក់ខែគោល៖ {$this->salary} $";
    }
}

class Manager extends Employee {
    public function __construct(
        string $name,
        float $salary,
        public float $bonus // Bonus បន្ថែមពិសេសសម្រាប់ Manager
    ) {
        parent::__construct($name, $salary); // ហៅ Parent Constructor
    }

    // Method Overriding: បង្កើនសមត្ថភាព getSalaryDetails() ដើម
    public function getSalaryDetails(): string {
        $total = $this->salary + $this->bonus;
        return parent::getSalaryDetails() . " + ប្រាក់រង្វាន់៖ {$this->bonus} $ = សរុប៖ {$total} $";
    }
}

$mgr = new Manager("សឿង លីម", 1500.00, 500.00);
echo $mgr->getSalaryDetails();
?>

enterprise_user_hierarchy.php
<?php
declare(strict_types=1);

class User {
    public function __construct(
        protected string $username,
        protected string $email
    ) {}

    public function getDetails(): string {
        return "User: {$this->username} ({$this->email})";
    }
}

class Employee extends User {
    public function __construct(
        string $username,
        string $email,
        protected float $salary
    ) {
        parent::__construct($username, $email);
    }

    #[\Override]
    public function getDetails(): string {
        return parent::getDetails() . " | ប្រាក់ខែ៖ {$this->salary} $";
    }
}

class Manager extends Employee {
    public function __construct(
        string $username,
        string $email,
        float $salary,
        private float $allowance
    ) {
        parent::__construct($username, $email, $salary);
    }

    #[\Override]
    public function getDetails(): string {
        $totalSalary = $this->salary + $this->allowance;
        return parent::getDetails() . " + ប្រាក់ឧបត្ថម្ភ៖ {$this->allowance} $ = សរុប៖ {$totalSalary} $";
    }
}

$mgr = new Manager("lim_soeurng", "lim@au.edu.kh", 1800.00, 400.00);
echo $mgr->getDetails();
?>
