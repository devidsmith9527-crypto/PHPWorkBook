៤.១.១ HTTP GET Method & $_GET Superglobal

Public Data Passing: URL Query Strings, Bookmarks, and Search Forms

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY
🎯 គោលគំនិត ៖ HTTP GET Method ផ្ញើទិន្នន័យចំហរនៅលើ URL Query String (ឧ. search.php?q=PHP&cat=books)។ ស័ក្តិសមសម្រាប់ Form ស្វែងរក (Search) និង Filter។

C1 ទម្រង់ទូទៅ (General Syntax)

<!-- HTML Form --> <form method="GET" action="target.php"> <input type="text" name="param_name"> </form> // PHP Accessing GET Parameter $value = $_GET['param_name'] ?? 'default_value';

⚠️ បម្រាមដាច់ខាត ៖ ហាមប្រើ GET Method សម្រាប់លេខសម្ងាត់ (Password) ឬព័ត៌មានកាតធនាគារ ព្រោះវាបង្ហាញចំហរលើ URL និង Browser History!

កូដ PHP អនុវត្តជាក់ស្តែង

<?php $keyword = $_GET['q'] ?? ''; $category = $_GET['cat'] ?? 'all'; ?> <form method="GET" action="get_demo.php"> <input type="text" name="q" value="<?= htmlspecialchars($keyword) ?>"> <button type="submit">ស្វែងរក</button> </form> <?php if (!empty($keyword)): ?> <p>លទ្ធផលស្វែងរក៖ <b><?= htmlspecialchars($keyword) ?></b></p> <?php endif; ?>
Output: លទ្ធផលស្វែងរក៖ PHP 8 (ប្រភេទ៖ books)

៤.១.២ HTTP POST Method & $_POST Superglobal

Secure Payload Transmission: Request Body, Login Forms, and Sensitive Data

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY
🎯 គោលគំនិត ៖ HTTP POST Method ផ្ញើទិន្នន័យបង្កប់ក្នុង HTTP Request Body ដោយមិនបង្ហាញលើ URL Bar ឡើយ។ ស័ក្តិសមសម្រាប់ Form Login, Register, និង File Upload។

C1 លក្ខណៈពិសេសនៃ POST

  • Security ៖ លាក់ទិន្នន័យមិនឱ្យបង្ហាញលើ URL Address Bar។
  • No Length Limit ៖ គ្មានកំណត់ប្រវែងទិន្នន័យ (កំណត់ដោយ post_max_size ក្នុង php.ini)។
  • Data Mutation ៖ ប្រើសម្រាប់ប្រតិបត្តិការ Create, Update, Delete។
<form method="POST" action="login.php"> <input type="password" name="password"> </form> $pwd = $_POST['password'] ?? '';

កូដ PHP អនុវត្តជាក់ស្តែង

<?php $username = $_POST['username'] ?? ''; $password = $_POST['password'] ?? ''; ?> <form method="POST"> <input type="text" name="username" value="<?= htmlspecialchars($username) ?>"><br> <input type="password" name="password"><br> <button type="submit">ចូលប្រព័ន្ធ (Login)</button> </form> <?php if ($_POST): ?> <div>ទទួលទិន្នន័យ POST ពី៖ <?= htmlspecialchars($username) ?></div> <?php endif; ?>
Output: ទទួលទិន្នន័យ POST ពី៖ lim_admin (URL មិនប្រែប្រួល)

៤.១.៣ Request Detection ជាមួយ $_SERVER["REQUEST_METHOD"]

Execution Routing: Distinguishing Initial Page View (GET) from Submission (POST)

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY
🎯 គោលគំនិត ៖ ប្រើប្រាស់ $_SERVER["REQUEST_METHOD"] === "POST" ដើម្បីបែងចែកដាច់ស្រឡះរវាងការបើកមើលទំព័រដំបូង (GET) និងការចុច Submit Form (POST)។

C2 គោលការណ៍ត្រួតពិនិត្យ

ការប្រើ $_SERVER["REQUEST_METHOD"] === "POST" ផ្តល់នូវភាពសុក្រឹតខ្ពស់ជាងការប្រើ isset($_POST['submit']) ព្រោះពេលខ្លះប៊ូតុង Submit គ្មានឈ្មោះ name ឬ User ចុច Enter លើ Input Field។

if ($_SERVER["REQUEST_METHOD"] === "POST") { // Form processing logic } else { // Initial GET request view logic }

កូដ PHP អនុវត្តជាក់ស្តែង

<?php $message = ''; // ត្រួតពិនិត្យថា User ផ្ញើតាម POST ឬទេ? if ($_SERVER["REQUEST_METHOD"] === "POST") { $email = $_POST['email'] ?? ''; $message = "អរគុណ! អ៊ីមែល " . htmlspecialchars($email) . " ត្រូវបានចុះឈ្មោះរួចរាល់។"; } ?> <form method="POST"> <input type="email" name="email" required> <button type="submit">Subscribe</button> </form> <?php if ($message): ?> <p><?= $message ?></p> <?php endif; ?>

៤.២.១ Server-Side Empty Check & String Trimming

Data Integrity: Sanitizing Whitespace and Detecting Empty Values

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY
🎯 គោលគំនិត ៖ ត្រូវតែប្រើ trim() កាត់ចន្លោះ Space ដើម-ចុងចោលជានិច្ច មុននឹងយកទៅ Check ជាមួយ empty() ឬ strlen()។

C3 គ្រោះថ្នាក់នៃការមិនប្រើ trim()

ប្រសិនបើ User វាយតែចន្លោះទំនេរ " " (Spaces) ដោយគ្មាន trim() នោះ empty(" ") នឹងប្រគល់ false ដែលធ្វើឱ្យកូដយល់ច្រឡំថាទិន្នន័យនោះត្រឹមត្រូវ!

$fullname = trim($_POST['fullname'] ?? ''); if (empty($fullname)) { $errors['fullname'] = "សូមបញ្ចូលឈ្មោះពេញ!"; }

កូដ PHP អនុវត្តជាក់ស្តែង

<?php $errors = []; $fullname = ''; if ($_SERVER["REQUEST_METHOD"] === "POST") { $fullname = trim($_POST['fullname'] ?? ''); if (empty($fullname)) { $errors['fullname'] = "សូមបញ្ចូលឈ្មោះពេញរបស់អ្នក!"; } elseif (strlen($fullname) < 3) { $errors['fullname'] = "ឈ្មោះត្រូវមានយ៉ាងតិច ៣ តួ!"; } } ?>
Output: បើ User វាយ " " -> លោត Error: "សូមបញ្ចូលឈ្មោះពេញរបស់អ្នក!"

៤.២.២ Data Filter Validation ជាមួយ filter_var()

Standard Validation: Verifying Email, Integer, and URL Data Formats

សាកលវិទ្យាល័យអង្គរ ANGKOR UNIVERSITY

C3 អនុគមន៍ filter_var()

ជួយផ្ទៀងផ្ទាត់ទម្រង់ទិន្នន័យស្មុគស្មាញដោយមិនបាច់សរសេរ Regex ដោយដៃ ៖

  • FILTER_VALIDATE_EMAIL ៖ ផ្ទៀងផ្ទាត់អាសយដ្ឋាន Email
  • FILTER_VALIDATE_INT ៖ ផ្ទៀងផ្ទាត់ចំនួនគត់ Integer
  • FILTER_VALIDATE_URL ៖ ផ្ទៀងផ្ទាត់តំណភ្ជាប់ Web URL
if (!filter_var($email, FILTER_VALIDATE_EMAIL)) { $errors['email'] = "ទម្រង់អ៊ីមែលមិនត្រឹមត្រូវ!"; }

កូដ PHP អនុវត្តជាក់ស្តែង

<?php $email = trim($_POST['email'] ?? ''); $age = trim($_POST['age'] ?? ''); $errors = []; if ($_SERVER["REQUEST_METHOD"] === "POST") { if (!filter_var($email, FILTER_VALIDATE_EMAIL)) { $errors['email'] = "ទម្រង់អ៊ីមែលមិនត្រឹមត្រូវឡើយ!"; } // ប្រយ័ត្ន៖ ត្រូវប្រើ === false ជៀសវាងច្រឡំលេខ 0 if (filter_var($age, FILTER_VALIDATE_INT) === false) { $errors['age'] = "អាយុត្រូវតែជាតួលេខចំនួនគត់!"; } } ?>

State Preservation: checked and selected Attributes with in_array()

C3 Boolean HTML Attributes

  • Radio Buttons ៖ ប្រើ ($gender === 'male') ? 'checked' : ''

៤.៤.២ Post/Redirect/Get (PRG) Pattern ជាមួយ header()

  • បម្រាម "Headers already sent" ៖ header() ត្រូវហៅមុនពេលមាន HTML Output ទាំងអស់!
  • ត្រូវតែដាក់ exit(); ពីក្រោយ header() ជានិច្ច។
